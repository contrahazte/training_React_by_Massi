
 Prueba Técnica React (Nivel Junior - Medio)
🎯 Objetivo:
Crear una pequeña aplicación de React con una lista de tareas (To-do list) que permita añadir, completar, eliminar y filtrar tareas.

📝 Requisitos Técnicos
1. Crear un componente TaskApp que contenga:

Un input para ingresar tareas nuevas.

Un botón para añadir la tarea.

Un listado de tareas.

2. Cada tarea debe tener:

Un texto.

Un botón para marcar como completada.

Un botón para eliminarla.

3. Mostrar una lista filtrada con 3 botones:

Todas

Completadas

Pendientes

4. Estilos mínimos:

Cuando una tarea esté completada, su texto debe tener una línea tachada (text-decoration: line-through).

Usa CSS o Tailwind (opcionalmente).

🧪 Extras (Bonus)
Si quieres subir el nivel:

Guarda las tareas en localStorage.

Usa useReducer en lugar de useState.

Separa en múltiples componentes: TaskItem, TaskList, TaskForm.

Añade validaciones al input (no tareas vacías, máximo 100 caracteres).

Usa TypeScript para tipar los props y estados.

¿Quieres que te genere una estructura base de la app con los componentes y el código inicial para que empieces desde ahí?
